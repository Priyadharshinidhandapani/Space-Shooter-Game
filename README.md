# 🚀 Space Shooter

Space Shooter is a fast-paced arcade-style space shooter game built using React and Vite. Players control a glowing spaceship, destroy enemy ships, defeat boss enemies, unlock new levels, and achieve high scores in an animated neon galaxy battlefield.

## 🎮 Features

- 🚀 Arcade-style space shooter gameplay
- 📱 Mobile-first responsive controls
- 👾 Boss enemy battles
- 💥 Explosion animations
- ✨ Animated star background
- ❤️ Lives system
- 🔓 Level unlocking system
- 🏆 Score tracking
- 🎯 Smooth touch and keyboard controls
- 🌌 Neon arcade UI design

## 🕹 Controls

### Desktop
- ⬅ Arrow Left → Move Left
- ➡ Arrow Right → Move Right
- SPACE → Shoot

### Mobile
- Touch controls available at bottom of screen

## ⚙️ Technologies Used

- React
- Vite
- CSS3
- JavaScript
